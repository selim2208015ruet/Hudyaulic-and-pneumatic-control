# Hydraulic & Pneumatic Control

## 📖 About

Hydraulic and Pneumatic Control involves the design and control of systems using pressurized fluids and compressed air for industrial automation and motion control.

## 🛠️ Software

* **FluidSIM** — Circuit design, simulation, and analysis.

## 📂 Contents

* Hydraulic control circuits
* Pneumatic control circuits
* Circuit diagrams
* Simulation results

## 📸 Simulation Files

All circuits and simulations in this repository are created and tested using **FluidSIM**.
Since the pre-installed version of FluidSIM used for this work does not support saving project files, the completed circuits and simulation results are provided as **PNG images**.

## 🎯 Objective

To understand, design, simulate, and analyze different hydraulic and pneumatic control systems using FluidSIM.
